## REQUIRES
python, pygame


## INFO jp
・矢印キーで移動(止まれない)
・スペースキーで分身を作れる
・直近の移動方向と反対に分身が生まれる
・すでに何かがある場合分身は作れない
・残りの分身の個数は左上のアイコンの数
・残りの手数制限は左上に数字で書いてある
・複数あるゴールに同時にプレイヤーが存在した場合、ゴールとなる。
・ゴールの判定は動いているかどうかは関係ない
・Rキーでリスタート
